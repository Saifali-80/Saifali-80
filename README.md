I'm a freelance Full-Stack Developer based in Pakistan, specializing in the MERN stack with a growing edge in AI-powered product development. My work sits at the intersection of modern web engineering and intelligent systems — building applications that are fast, scalable, and designed to deliver measurable value.

With a foundation in JavaScript/TypeScript across the full stack, I architect and ship complete web solutions: from database design and API development to polished, responsive front-end experiences.
